Market Indices

An index is a rule-based measurement portfolio. Its result depends on selection, weighting, rebalancing and return treatment.

Four choices create an index

  1. Universe and eligibility: which securities can enter?
  2. Selection: which eligible securities represent the intended market?
  3. Weighting: how much does each constituent influence the result?
  4. Maintenance: when are weights reset and members replaced?

Nifty, Sensex, S&P 500, Nasdaq indices and MSCI indices answer different questions. The number of constituents alone does not define breadth, and an index provider is not necessarily an exchange.

Nifty 50 uses free-float market capitalisation, so strategic holdings excluded from free float do not contribute equally to investable weight. Price index and total-return index

A price index tracks constituent prices after methodology adjustments. A total-return index also assumes distributions are reinvested under its rules. Comparing a portfolio that receives dividends with a price-only benchmark understates the benchmark's return.

{{i:prohibit}} Common misconception

“The index rose 12%, so every constituent rose about 12%.”

Why this failsConstituent returns differ and weights differ. A small set of large weights can dominate the index.

Better questionWhich constituents and weights produced the change, and is this a price or total-return index?
