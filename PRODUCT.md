# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Native HTML, CSS, and JavaScript authored as reusable shared and module-specific source. A Node.js build compiles each module into one standalone HTML artifact for dependable learning and distribution.

## Users

The primary learner has limited formal finance education, some exposure to investing, and enough technical confidence to learn applied mathematics and basic programming. They want depth without unnecessary jargon, with both Indian and global context, and ultimately want to use quantitative methods, data, technology, and AI responsibly.

## Product Purpose

Finance Academy develops financial judgment from personal-finance foundations through investment analysis, portfolio construction, quantitative research, AI-assisted workflows, and professional practice. Success means the learner can make, explain, test, and improve financial decisions after the lesson is closed.

## Positioning

The curriculum behaves as an interactive financial laboratory with an expert tutor built into it. Concepts progress from purpose and intuition through prediction, manipulation, calculation, explanation, failure analysis, and transfer to unfamiliar situations.

## Operating Context

Learners move through a module using a persistent lesson list, read one lesson at a time, manipulate financial explorers, answer predictions and checks, inspect charts and tables, keep private notes, and complete practical projects. Module 0 culminates in a browser-local Personal Financial Dashboard covering the full chain from income and expenses to goals.

## Capabilities and Constraints

- The program contains 26 levels across personal finance, markets, investment analysis, portfolios, risk, trading, quantitative finance, AI, data, automation, and professional practice.
- Module 0 contains an overview, 11 lessons, synthesis, mastery assessment, and Project 0.
- Learning modules preserve syllabus order, stable lesson IDs, factual copy, source categories, and financial calculation behavior.
- Core modules should work as standalone artifacts with few external dependencies.
- Current facts must be sourced, date-stamped, and reverified before release.
- Financial calculations come from unit-tested engines. Examples must distinguish hypothetical, historical, and current data.
- Learner notes, progress, and Project 0 data stay in the browser. Nothing is sent to a server.
- Visuals and interactions must teach a relationship, reduce complexity, improve comparison, or provide meaningful feedback.

## Brand Commitments

The product name is Finance Academy. Its voice is calm, direct, rigorous, encouraging, and intellectually respectful. It avoids hype, return promises, decorative financial clichés, unnecessary jargon, and generic AI-generated aesthetics. The course uses Indian financial conventions where relevant while teaching globally transferable reasoning.

## Product Principles

1. Optimize for understanding that survives after the page is closed.
2. Teach why and intuition before notation, then require prediction and transfer.
3. Make assumptions, uncertainty, risk, sources, and model limits visible.
4. Use interaction as a learning instrument, never as decoration.
5. Preserve learner agency, privacy, accessibility, and a clear path through difficult material.

## Accessibility & Inclusion

The experience must support keyboard navigation, semantic structure, visible focus, WCAG AA contrast, non-color cues, reduced motion, touch-friendly controls, 200% zoom, mobile layouts, chart text alternatives, and clear form labels. New learners are never treated as unintelligent because a concept is unfamiliar.
